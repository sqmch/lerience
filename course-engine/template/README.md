# Lerience course

This repository is a personal course created by Lerience. The course itself is ordinary
files and Git history: `COURSE.md` is its spine, `curriculum/` contains modules, and `tutor/`
contains the durable learning record.

Lerience is the designed way to study it. A power user can also open this folder directly in
Claude Code, Codex, or another compatible local agent; `CLAUDE.md` contains the tutor protocol
and `AGENTS.md` points agent-agnostic clients to it. Deterministic maintenance commands remain
available through `npm run doctor`, `npm run validate`, `npm run qa`, and `npm run quiz`.

Files supplied by the Course Engine are updated only through an explicit Lerience operation.
Course content and learner state live on separate paths and are never silently changed by an app
update.
