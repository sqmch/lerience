## Publication blockers and honest limits

- Neither downloaded Mac DMG has passed first-launch Gatekeeper handling, provider discovery,
  course creation, or the ordinary learner path on physical native hardware. The Intel DMG
  specifically requires a physical Intel Mac run. One architecture cannot accept the other.
- The downloaded Windows installer has not passed an isolated 0.0.7 to 0.0.8 in-app update. This
  release changes the verified NSIS handoff to run silently, so that exact installed-upgrade path
  must be exercised with a disposable Windows account, VM, or isolated preview identity.
- No exact 0.0.8 downloaded package has completed uninstall and learner-data preservation checks.
- The packages intentionally have no trusted operating-system signatures. The app-owned Ed25519
  manifest protects update selection and package bytes but does not remove SmartScreen or
  Gatekeeper warnings.
- The draft remains unpublished. Publish it unchanged only after the missing Windows update and
  separate physical Mac acceptance results are added to this record and pass.
