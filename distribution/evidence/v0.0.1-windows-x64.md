## Learner-path result and honest limits

- The preceding exact Setup candidate passed a normal visible learner path on the maintainer's
  Windows account: installed-provider discovery, course creation, tutor operation, and generated
  course material worked without developer tooling.
- The installer-only replacement changes the packaging target, signing/staging scripts, workflows,
  and public documentation. It does not change application source, provider code, dependencies,
  package metadata, Course Engine bytes, or runtime inputs. The prior visible smoke is therefore
  accepted as functional evidence for this first preview, while the downloaded replacement bytes
  independently passed installation and packaged-app verification above.
- The acceptance host was not a clean Windows account or VM. An additional provider-specific smoke
  remains useful follow-up evidence rather than a publication blocker.
- There is no earlier public Lerience version against which to exercise the full in-app upgrade and
  learner-data preservation path. Automated update-trust tests are green; the native upgrade path
  remains an acceptance item for the first patch release.
- The Windows package intentionally has no commercial operating-system code-signing certificate.
  Windows may show an unknown-publisher warning; the Ed25519 signature protects the Lerience update
  manifest and does not remove that warning.
- The accepted draft was published without changing its assets on 2026-08-19 at 00:03:19 UTC.
