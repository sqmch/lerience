## Outstanding physical checks

None of these checks was performed for this candidate, and none is reported as passed:

- Windows: installed Setup, publisher warning, launch, provider discovery, course creation, update from an earlier installed version, uninstall, and data preservation.
- macOS arm64: physical Gatekeeper approval and learner-path run.
- macOS x64: physical Intel Mac Gatekeeper approval and learner-path run. The Intel package still has no physical Intel Mac result.
- Providers: the changed Claude background/continuation handling, model and effort controls, context display, and explicit assessment review were not exercised in a live provider session as part of this candidate.
- Existing courses: this release does not apply Course Engine updates to them. Their QA cleanup and new capabilities require a separate explicit update action.

The unsigned-preview rule permits these physical checks as post-publication debt for this release. Source tests, native package verification, and downloaded-byte integrity passed; they do not establish installed-path or live-provider behavior.
