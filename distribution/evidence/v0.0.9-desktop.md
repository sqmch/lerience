## Native acceptance debt and honest limits

- Neither downloaded Mac DMG has passed first-launch Gatekeeper handling, provider discovery,
  course creation, or the ordinary learner path on physical native hardware. The Intel DMG still
  requires a physical Intel Mac run. One architecture cannot accept the other.
- The downloaded Windows installer has not passed an isolated `0.0.8` to `0.0.9` in-app update.
  The installed learner-path check must also confirm that Codex onboarding can save `COURSE.md` and
  that longer tutor operations report useful progress without exposing raw commands.
- No exact `0.0.9` downloaded package has completed uninstall and learner-data preservation checks.
- The packages intentionally have no trusted operating-system signatures. The app-owned Ed25519
  manifest protects update selection and package bytes but does not remove SmartScreen or
  Gatekeeper warnings.
- The release is public and is the current `releases/latest` target. The missing installed Windows
  and separate physical Mac checks remain post-publication acceptance debt and must not be reported
  as passed.
