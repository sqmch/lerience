- macOS arm64: no physical Gatekeeper approval or learner-path run.

- Updater: no installed-upgrade run exercising the Windows silent handoff from a prior version.

  session controls both hold deterministic test coverage only. Neither has been exercised against a
  live Codex or Claude Code session.

These are acceptance debt against a community preview, carried deliberately. A later release that
changes native packaging, manifest signing or selection, the update handoff, or a compatibility
range cannot inherit this record and must produce its own native results.
