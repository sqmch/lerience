# Lerience 0.0.10

This release makes course creation and first-module building easier to follow, and moves update
progress into quieter, persistent controls.

## Changed

- Turn a rough course title or topic sentence into a portable folder name, and preview that folder
  before creation. The original words still seed the tutor's interview.
- Replace the first-module file stream with a stable seven-part progress summary. Filtered file
  details remain available when they are useful.
- Show the requested command and its working location on tutor approval cards. Longer completion
  summaries can now be expanded in place.
- Move update state into the status bar, with a toast for important moments and a focused dialog for
  download, install, retry, and release-note actions.
- Render the drafted course outline at a calmer reading size before the learner approves module 00.

## Known limitations

- The desktop packages do not yet carry trusted operating-system signatures. Windows may show an
  unknown-publisher or SmartScreen warning. On macOS, the first launch must be approved under
  System Settings > Privacy & Security.
- macOS uses separate Apple Silicon and Intel downloads. Both native packages are built and checked
  independently before publication.
- Provider compatibility depends on the stable interfaces exposed by the provider-owned clients.
