# Lerience 0.0.15

New courses can save optional assessment answers and Lesson highlights. Tutor activity and session controls are clearer, and Course Engine QA no longer removes dependencies through a temporary Windows junction.

## Added

- Save drafts for optional numeric prediction and explanation activities, submit local attempts, and request tutor feedback explicitly. Attempts travel with a copied course. Numeric checks and tutor feedback do not change progress or quiz grades.
- Highlight Lesson passages from a selection or context menu, then return to them from a course-wide saved list. A keyboard paragraph chooser is available. Highlights travel with a copied course; when a passage changes or disappears, its quote remains in the list without guessing a new location.
- Show estimated tutor context use when a provider reports both usage and a context window. This is a context estimate, not an account allowance or a promise to prevent compaction.

## Changed

- Update the bundled Course Engine to 0.4.0. Version 0.2.1 changes Windows QA cleanup to unlink temporary junctions without recursively removing their targets. Versions 0.3.0 and 0.4.0 add the separately negotiated assessment and reading capabilities for newly created courses.
- Show Claude's reported allowance percentage with the correct limit label, and show background task activity separately from the foreground turn. A resumed provider turn now has its own visible boundary.
- Allow model choice before the first tutor message and keep effort choices compatible with the selected model. Saved session-control labels take less space.
- Keep a reader's scroll position while a reply streams, identify same-named labs by module, and keep module-build elapsed time on one line.

## Known limitations

- Existing courses keep their current Course Engine scripts and do not gain the new assessment or highlight capabilities, or the Windows QA cleanup fix, from an app update alone. Course Engine updates require a separate explicit action.
- Windows console flashes and some interrupted-session recovery behavior remain under investigation.
- Desktop packages are unsigned at the operating-system level. Windows may show an unknown-publisher warning; macOS first launch requires approval in System Settings. Apple Silicon and Intel Macs have separate downloads.
- Tutor clients remain separately installed and authenticated. Lerience does not install or update Codex or Claude Code.
