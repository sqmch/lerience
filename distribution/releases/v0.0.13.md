# Lerience 0.0.13

Lessons now render Mermaid diagrams, keep interactive visuals present while reading, and open
course source links in the selected editor. The bundled Course Engine also plans smaller modules
around a complete learning cycle.

## Changed

- Update the bundled Course Engine to 0.1.2. Each module targets one main outcome and a manageable
  30–60 minute cycle including reading, practice, tutor discussion, and retrieval. Scope checks flag
  unusually long lessons for review; daily availability guides scheduling rather than lesson size.
- Render Mermaid diagrams in lessons and briefs with theme-aware styling, fit-width and actual-size
  views, and access to the original source. Invalid diagrams retain a readable source fallback.
- Keep embedded interactive visuals mounted when the lesson's parent view updates, preserving their
  state while reading and scrolling.
- Open course-relative source links in the selected editor, reusing an existing editor window where
  supported. Supported document and image links open in their associated application. Missing or
  unavailable files now show a useful error.

## Known limitations

- The desktop packages do not yet carry trusted operating-system signatures. Windows may show an
  unknown-publisher or SmartScreen warning. On macOS, the first launch must be approved under
  System Settings > Privacy & Security.
- macOS uses separate Apple Silicon and Intel downloads. Both native packages are built and checked
  independently by the release workflow.
- Tutor clients remain separately installed and authenticated. Lerience does not install or update
  Codex or Claude Code.
- Existing courses keep the Course Engine files they were created with. Lerience does not silently
  replace a learner's course protocol or split existing modules.
- Source links must resolve to files inside the course folder. Editor window reuse and line-number
  navigation depend on the selected editor.
