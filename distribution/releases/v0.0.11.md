# Lerience 0.0.11

This release fixes Windows Codex course-write failures and gives conversations and course material
more reading space.

## Fixed

- Find complete installed Windows Codex runtimes, including the desktop app's runtime directories.
  Skip installations missing the helpers needed to write inside the course sandbox.
- Verify an actual sandboxed write before starting the tutor interview. If Codex cannot write,
  show a repair message immediately and preserve the course and conversation for retry.

## Changed

- Widen the onboarding conversation and lesson/brief reading limit by 20%, with font sizes unchanged.
  The default course tutor pane also provides 20% more readable space. Existing pane-width
  preferences remain respected.
- Give tutor-selection cards a consistent layout and one clear status line.

## Security

- Update the fast-uri dependency to 3.1.6 to address published URL-parsing security advisories.

## Known limitations

- The desktop packages do not yet carry trusted operating-system signatures. Windows may show an
  unknown-publisher or SmartScreen warning. On macOS, the first launch must be approved under
  System Settings > Privacy & Security.
- macOS uses separate Apple Silicon and Intel downloads. Both native packages are built and checked
  independently before publication.
- Tutor clients remain separately installed and authenticated. Lerience does not install or update
  Codex or Claude Code.
