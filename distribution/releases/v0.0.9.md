# Lerience 0.0.9

This release fixes Codex course creation and makes longer tutor operations easier to follow.

## Changed

- Give Codex tutors course-scoped write access so onboarding can save `COURSE.md` and later
  sessions can update curriculum, tutor state, and learner artifacts. Lerience now stops the
  session at startup if Codex does not return the required writable profile.
- Show what the tutor is doing in the waiting line, including safe file or task detail and elapsed
  time for longer steps. Approval cards now say when the tutor is waiting for the learner without
  exposing raw commands.

## Known limitations

- The desktop packages do not yet carry trusted operating-system signatures. Windows may show an
  unknown-publisher or SmartScreen warning. On macOS, the first launch must be approved under
  System Settings > Privacy & Security.
- macOS uses separate Apple Silicon and Intel downloads. Both native packages are built and checked
  independently before publication.
- Provider compatibility depends on the stable interfaces exposed by the provider-owned clients.
