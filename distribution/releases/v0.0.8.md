# Lerience 0.0.8

This release speeds up repeat launches, improves the Windows update handoff, and sharpens tutor
onboarding and workspace controls.

## Changed

- Reuse verified runtime hashes when the installed payload has not changed, while keeping complete
  uncached verification for release acceptance and repair checks.
- Install a verified Windows update silently after the learner chooses to restart, without
  reopening the installer wizard.
- Probe the learner's starting knowledge during onboarding, record useful calibration evidence,
  check untested prerequisites, and require a short teach-back before completing a module.
- Keep the editor handoff and session controls usable at narrow window sizes by moving them out of
  the material tab row and into the seminar header.
- Present `End session` as a consistent control and remove the shifting next-reply hint from the
  session settings row.

## Known limitations

- The desktop packages do not yet carry trusted operating-system signatures. Windows may show an
  unknown-publisher or SmartScreen warning. On macOS, the first launch must be approved under
  System Settings > Privacy & Security.
- macOS uses separate Apple Silicon and Intel downloads. Both native packages are built and checked
  independently before publication.
- Provider compatibility depends on the stable interfaces exposed by the provider-owned clients.
