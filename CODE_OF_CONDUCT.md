# Code of conduct

This project aims to be a careful, welcoming engineering effort. Participation in its repositories
and project spaces requires professional, good-faith collaboration.

Expected behavior includes:

- discussing ideas and code without attacking people;
- being specific, evidence-led, and open to correction;
- respecting privacy, credentials, learner data, and responsible-disclosure boundaries;
- making room for different backgrounds and levels of experience; and
- accepting maintainer decisions about scope while remaining free to disagree constructively.

Harassment, discrimination, threats, sexualized attention, doxxing, deliberate disruption, and
publication of private or security-sensitive information are not acceptable.

Report conduct concerns privately to the repository maintainer through GitHub. Reports will be
handled with discretion. Proportionate responses may include a warning, removal of content,
temporary participation limits, or a permanent ban. Good-faith security research conducted under
`SECURITY.md` is not a conduct violation.
