# Support

Lerience publishes unsigned Windows community previews through
[GitHub Releases](https://github.com/sqmch/lerience/releases). They are suitable for early use and
feedback but do not yet carry a trusted Windows publisher signature.

For source questions, documentation gaps, or reproducible application defects:

- use a GitHub issue for reproducible application defects or documentation gaps;
- include the app version, operating system, provider name and version, and safe reproduction steps;
- remove credentials, personal course content, transcripts, and private filesystem paths; and
- report security-sensitive behavior through [SECURITY.md](SECURITY.md), not an issue.

Provider installation, authentication, billing, availability, and account policy remain the
provider's responsibility. Lerience should present accurate guidance, but it cannot repair or bypass
provider-owned state.
